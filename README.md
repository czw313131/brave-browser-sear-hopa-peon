# 新搜尋分頁

一個為 Brave 瀏覽器客製化的搜尋分頁，整合 Startpage 搜尋引擎與即時天氣資訊。

![gallery](https://ibb.co/pj18K8nH](https://i.meee.com.tw/OGpGnor.webp)

## 功能特色

### 🔍 搜尋框
- 以 Startpage 搜尋引擎為後端
- 支援快速搜尋（按 Enter 鍵即可）
- 響應式設計，適配電腦和手機

### 🌤️ 天氣卡片
實時顯示天氣相關資訊：
- **地點**：顯示當前位置
- **風向指南針**：以視覺化指針呈現風向角度（0°～360°）
- **氣壓表**：動態指針顯示大氣壓力（hPa）

### 🎨 設計特點
- 深色主題配色
- 優雅的玻璃態效果
- 全面支援觸控裝置
- 流暢的響應式佈局

## 使用方式

1. 將 `index.html` 設為瀏覽器首頁
2. 確保 `weather.json` 在同一目錄
3. 在搜尋框中輸入關鍵字並按 Enter 開始搜尋

## 文件說明

- `index.html` - 主頁面
- `weather.json` - 天氣資料（包含位置、風向、氣壓等）
- `LICENSE` - 使用授權
